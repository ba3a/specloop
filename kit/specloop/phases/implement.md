## Phase: implement

Implement the specification at `{spec}` following the checklist in `{run_dir}/plan.md`.

- Tick checklist items in `{run_dir}/plan.md` as you complete them.
- Reviews of earlier attempts are in `{run_dir}/attempts/single-*/review.md`, and `{run_dir}/last-failure.md` holds the latest rejection. Address every point in them.
- Run only targeted tests: the tests that cover your change, plus any linter and type checker the project uses. Do not run the full test suite. The quality gates run it when your turn ends and are the guarantee.
- Do not commit, push, or open pull requests.

{quality_gates}
